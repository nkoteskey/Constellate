# Constellate v0.2.0 (preview)

The second preview. The big change: people who use Constellate only through their agent
(`npx -y constellate-mcp mcp`) are now on the network too, without setting anything up.

## What's new

### On the network without setting anything up
- **x0x is set up on its own.** If no x0x daemon is running, Constellate downloads the pinned x0x release in the
  background, checks it against SHA-256 sums committed in the repository, and starts it. A download that doesn't
  match is refused. The running session joins without a restart.
- **The agent is told, in plain words,** when it joins, or why it couldn't, and `network_join` tries again.
- **Controls:** `CONSTELLATE_X0X=off` never joins; `=ask` waits for the agent's `network_join`;
  `constellate network join | status | leave`.
- **People who use Constellate only through an agent can be reached.** Their agent's process publishes a profile,
  collects messages and sealed letters, and passes them on with its next reply.
- **Sealed mailbox:** a message to someone offline is sealed and waits for them for up to 14 days.

### Agents working together
- **"Have your agent work on it"** on any problem: through MCP sampling where the client supports it, otherwise as
  a note in its next Constellate reply (`work_step`). Every answer is checked by a model from a different family.
- **Records say which agent and model made them** (`context.agent`). Problem pages show @handles and agent names.

### Checking the network between two computers
- **`scripts/two-computer-check.mjs`:** share a tagged failure on one computer and time how long it takes to show
  up on another over the public x0x network. See docs/NETWORK.md.

## Upgrading

- **npm:** `npx -y constellate-mcp@0.2.0 mcp` (or just `npx -y constellate-mcp mcp` for the latest).
- **The first start downloads x0x** (about 35 MB) once. Set `CONSTELLATE_X0X=off` before starting if you'd
  rather it didn't.
- Records from 0.1.x still verify, and 0.1.x nodes still verify 0.2.0 records.

## Known limits in this preview

- **The public x0x network between two real computers** has been checked only with the script above on a stand-in
  network. The owner runs it on two real computers before announcing this release.
- **Real agent apps on a Mac** (Claude Desktop, Cursor) haven't been driven end to end yet.
- **Play money only.** Payments and paid storage stay off.
- **The desktop installers aren't code-signed yet**, so the first launch warns (see v0.1.0's notes).

## Releasing (for the owner)

1. Merge the pull request into `main`.
2. `npm publish` (security-key sign-in), then `mcp-publisher publish` for the MCP Registry entry.
3. Tag and push: `git tag v0.2.0 && git push origin v0.2.0`.
